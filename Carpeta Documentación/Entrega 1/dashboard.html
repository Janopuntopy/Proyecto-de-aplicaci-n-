Visión General del Proyecto

Problemática

La gestión manual de eventos dificulta el manejo de grandes volúmenes. Las cancelaciones de última hora sin un mecanismo formal de notificación impactan negativamente en la planificación, ventas y consumo de productos en el local.

Solución

Desarrollo de una app móvil híbrida y microservicios API REST. Permitirá automatizar inscripciones, gestionar eventos y enviar notificaciones en tiempo real sobre cupos liberados, mejorando la logística del local.

Arquitectura y Lógica de Despliegue

1. Interacción del Usuario (Frontend)

La app híbrida (Ionic/Angular) captura las acciones del usuario (reservas, cancelaciones) y envía peticiones HTTP en formato JSON.

2. Contenerización con Docker

El microservicio backend en Java (Spring Boot) se empaqueta en una imagen de Docker, garantizando portabilidad y consistencia entre entornos.

3. Ejecución Serverless (Google Cloud)

La imagen Docker se despliega en Google Cloud Run, permitiendo auto-escalado según la demanda de los eventos.

4. Persistencia de Datos

Los datos se almacenan en Firestore (NoSQL) para lecturas rápidas en tiempo real, validando la seguridad mediante Firebase Admin SDK.
